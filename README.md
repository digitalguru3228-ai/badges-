# 🚀 Badges & Digital Logic Portfolio

Welcome to the **Badges** repository! This project serves two main purposes:
1. Exploring and implementing foundational Digital Electronics concepts (Adders, Subtractors, K-Maps, and Truth Tables).
2. Demonstrating active GitHub contribution workflows, CI/CD practices, and open-source engagement.

## 📌 Featured Digital Logic Implementations
* **Full Adder**: Circuit implementation, Truth Table analysis, and K-Map minimization ($AB + BC_{in} + AC_{in}$).
* **Full Subtractor**: Truth table verification, Borrow output logic ($A'B + A'B_{in} + BB_{in}$), and 3-input XOR Difference mapping.
* **Half Subtractor**: Truth table and simplified logic equations ($\text{DIFF} = A \oplus B$, $\text{BORROW} = A'B$).
